faq

learning {{ lname }} with weirdfriends

Is weirdfriends good for learning {{ L.name }} as a beginner?
Yes, from A1 up, though it shines from A2 or B1 when you can form basic sentences and need somewhere to use them. Set your level and your friends adjust how they text. Complete beginners often pair it with a basics course and use weirdfriends for the part courses skip: actually using {{ L.name }}.
Does it correct my {{ L.name }} mistakes?
Yes. A dedicated correction model reads every message you send. Mistakes are underlined; tap one for the correction and a short explanation in English. Messages with no mistakes earn +10 points.
Can I create my own {{ L.name }}-speaking character?
Yes. Give them a name, an emoji and a personality in a sentence or two. They'll text you in {{ L.name }}, in character, and you can edit them any time. More on creating friends.
Can I translate what my friend says?
Tap any message for an instant English translation. Use it as much as you like; nobody's counting.
Is it free?
Yes. {{ L.name }} and every other language, every character, corrections, translations and notifications are free, with unlimited usage right now. No trial, no credit card. Paid plans are coming soon, so get in while it's free.
