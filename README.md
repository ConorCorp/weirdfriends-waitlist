# weirdfriends.app

Static marketing site for [weirdfriends.app](https://weirdfriends.app), deployed by GitHub Pages straight from `main`. Jekyll builds it on every push; there's no build step to run before committing.

## What's where

| Path | What it is |
| --- | --- |
| `index.html` | Home page: hero with the live chat demo, features, how it works, create-a-friend, notifications, corrections, scenes, languages, dark mode, comparison, pricing, FAQ, email form |
| `languages/index.html` | Index of all 24 languages |
| `_data/languages.yml` | **All language content** (intro, sample chat, tips, character) — edit this to change a language page |
| `_languages/<slug>.md` | One tiny front-matter file per language; rendered at `/learn/<slug>/` |
| `_layouts/language.html` | Template for the language pages |
| `compare/index.html` | weirdfriends vs Duolingo / Babbel / ChatGPT / tutors |
| `create/index.html` | Create-your-own-friend page, with the friend generator and idea cards |
| `blog/`, `_blog/`, `_layouts/post.html` | The blog (see below) |
| `_layouts/default.html` | HTML skeleton every page uses: head, nav, footer, scripts |
| `_includes/base.css` | Shared styles and the light/dark colour tokens |
| `_includes/head.html` | Meta tags, Open Graph, favicon, fonts, theme init |
| `_includes/nav.html`, `footer.html`, `store-buttons.html`, `scripts.html` | Shared chrome |
| `assets/screens/*.webp` | App screenshots (640px wide, from `biz/weirdfriends/app_stores/screenshots`) |
| `assets/og.png` | Share image used by Open Graph / Twitter cards |
| `llms.txt`, `robots.txt` | Plain-text summary for AI crawlers; crawler rules + sitemap pointer |
| `privacy.html`, `account-deletion-request.html`, `thanks.html`, `berlin/`, `onelink/` | Standalone pages, untouched by the layout system |

`sitemap.xml` is generated by the `jekyll-sitemap` plugin. Helper pages (`onelink`, `thanks`, `berlin`, `assets`) are excluded via `_config.yml`.

## Dark mode

Colours are CSS variables in `_includes/base.css`. Light is the cream/mint/lavender look; dark is the app's v1.8 palette (navy `#1f202e`, lavender-blue lines `#7681bc`, purple bubbles `#b998f6`). The site follows the system setting, and the moon button in the nav overrides it (stored in `localStorage` as `wf-theme`). Always use the semantic tokens (`--bg`, `--surface`, `--ink`, `--line`, `--muted`, `--mint`, `--lavender`, …) in new CSS so both themes work.

## Adding or editing a language

1. Edit the entry in `_data/languages.yml` (name, flag, greeting, character, intro, 3-line `dialogue`, 3 `tips`).
2. For a new language, also add `_languages/<slug>.md` with `slug`, `title`, `title_tag`, `description`, `bubble_only` (the greeting) and `lang_code`. Copy an existing one.

The home page grid, marquee, footer and `/languages/` pick it up automatically.

## Adding a blog post

```sh
make new title="my post title"
```

Each post is a folder in `_blog/` holding an `index.md` and any images for that post:

```
_blog/
  my-post-title/
    index.md
    cover.gif
```

Without a title the folder is named with today's date, e.g. `_blog/2026-09-08/`. The folder name is the URL, so `_blog/my-post-title/` is served at `/blog/my-post-title/`.

Front matter:

```markdown
---
title: my post title
date: 2026-09-08
author: Conor
description: one-line summary shown on the blog index and in search results (optional)
image: cover.gif               # featured image (optional)
---
```

`date` is required and sets the publish date and ordering. Posts dated in the future are not published until that date passes.

- **Featured image**: shown at the top of the post, on the blog index, and as the share preview. Add `image_alt:` for alt text.
- **Inline images**: `![alt text](screenshot.png)` next to the post.

## Previewing locally

One-time setup (Ruby 3.3 via rbenv, then the same gems GitHub Pages uses):

```sh
rbenv install -s 3.3.9   # .ruby-version pins the repo to this
make install
```

Then:

```sh
make serve
```

Open <http://localhost:4000>. Edits to markdown, layouts and includes rebuild automatically; changes to `_config.yml` need a restart. `make build` writes the site to `_site/`.

The Makefile exports a UTF-8 locale because the Sass step in the `github-pages` gem fails under a plain ASCII `LANG`.

## Regenerating the share image

`assets/og.png` was rendered from a small HTML file with headless Chrome at 1200×630. If the tagline or look changes, rebuild it the same way (any browser screenshot at 1200×630 works) and overwrite the file.
